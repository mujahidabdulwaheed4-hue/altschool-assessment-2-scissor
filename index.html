! FAQs

How does URL shortening work?

URL shortening turns a long web address into a shorter link that redirects people to the original destination when opened.

Is it necessary to create an account to use the URL shortening service?

You can explore basic link shortening without an account. Creating an account gives you access to saved links and additional tools.

Are the shortened links permanent? Will they expire?

Links remain available according to the service plan and account settings. Check the terms for any applicable limits.

Are there any limitations on the number of URLs I can shorten?

Usage limits depend on the plan you choose. The pricing section gives an overview of the available plans.

Can I customize the shortened URLs to reflect my brand?

Yes. Custom aliases and branded domains can make your shortened links easier to recognise.

Can I track the performance of my shortened URLs?

Analytics can show link activity and help you understand how people interact with your links.

How secure is the URL shortening service? Are the links protected against spam?

Use trusted links and review the service's security and abuse-prevention policies before sharing sensitive destinations.

What is a QR code and what can it do?

A QR code is a scannable code that can open a web address, making it easy to share a link in print or on-screen.

Is there an API available for integrating the URL shortening service into my own applications or websites?

API access may be available depending on the plan. Consult the product documentation for integration details.
